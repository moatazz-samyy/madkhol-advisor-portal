Recommended CEO walkthrough order

10–12 minutes. Hits every box in the diagram exactly once, in a sequence that tells a coherent story: discover assets → decide allocation → apply to clients → handle Saudi-specific obligations → grow the practice.

  1. Login → Dashboard. Show the four stat cards, Shariah alerts strip, top clients, activity feed, AI/Alpaca banners.
  2. Clients list → open one client → walk all 5 tabs. Portfolio, Performance, Activity, Documents, Notes.
  3. Asset Search. Type "AAPL". Point at the Purification / sh. column and the Min 1 share rule banner. Open the drawer.
  4. Select 3 assets → Optimizer. Run Mean-Variance, then Risk Parity, show how the weights shift.
  5. Apply weights to a Client (or to a Model). One click commits via server action.
  6. Sectors heatmap → drill into Tech → basket buy for the same client. Open the Client detail Activity tab; the new trades appear.
  7. Performance Projections. Run a 10-year Monte Carlo on that client's portfolio. Show the fan chart.
  8. Madkhol AI. Landing page — call out the 10K SAR / client minimum chip. Open the Connect modal, walk to step 2, close. Show the Suggestions inbox.
  9. Saudi differentiators, 30 seconds each: Shariah Dashboard → Zakat → Mirath → GOSI → Messages.
  10. Consumer Marketplace, new tab: /consumer/marketplace. Show the 10 advisor cards with the real Saudi portraits.
  11. Back to the app — Inquiries inbox → Profile editor. The matching advisor-side surface.
  12. Operational, fast click-through: Audit Log → Reporting → Billing → White-label.
  13. Logout. Back to Login screen — close the loop.
