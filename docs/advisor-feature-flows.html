1 · Authentication

No public sign-up — advisors are pre-onboarded by Madkhol Operations. The flow assumes an existing account.

Demo tip: Sign in as Saad (advisor1) for a populated book; Sara (advisor2) for a fresher feel and to show empty-states.

2 · Dashboard

The advisor's daily home screen. Glanceable health of the entire book in one view, with paths into every other feature.

Demo tip: Open as Saad — 12 clients, multiple Shariah alerts, several rows in the activity feed. Pause on the dashboard for 5 seconds before clicking anything; the density tells the story.

3 · Clients

List → filter → drill into a client → walk the 5 tabs. The advisor's most-visited module.

Demo tip: Open Saad's #1 client by AUM. Walk all 5 tabs in order; on the Notes tab, type a one-line note and Save to show the server action.

4 · Universal Asset Search

50-asset Saudi + global dataset. Filter, drill, select, route. The most-used cross-feature jumping-off point.

Demo tip: Type "AAPL" → point at purification column → open drawer → close → check 3 boxes → press "Optimize". Smooth transition to Flow 6.

5 · Sector Heatmap & Basket Trading

Top-down market view. Sectors → drill into one → select gainers/movers → basket buy for a chosen client in one shot.

Demo tip: Pick Tech, select the 3 top gainers, basket buy for ~50K SAR. Then jump to that client's Detail → Activity tab — the buys appear at the top of the timeline.

6 · Portfolio Optimizer

Pick assets → choose method → tweak constraints → run → apply weights. 4 methods produce 4 distinct curves.

Demo tip: Run Equal-Weight first (instant baseline), then Mean-Variance — point at how weights shift toward higher-Sharpe names. Tweak one slider, watch stats update. Apply to a model.

7 · Allocation Order

6-step wizard to route a SAR amount across multiple funds + multiple clients in one transaction.

Demo tip: Do a 100K SAR pro-rata-AUM order across 3 funds and 5 clients. Preview shows the math; confirm runs the server action. Check one client's Activity tab — buys are itemized.

8 · Rebalance

Detect drift across selected portfolios, review the trades needed, execute in one batch.

Demo tip: Select 3 clients with visible drift, set threshold to 5%, walk to Step 3 — point at how it shows BUYs and SELLs side by side. Don't actually execute unless you want the demo data to mutate.

9 · Model Portfolios

Reusable target allocations. Create → assign to many clients in one action.

Demo tip: Open one of Saad's existing models, click "Apply to clients" — select 3 — confirm. Then jump to one of those clients' Detail to show the assignment took effect.

10 · Madkhol AI Trading

Connect the AI trading engine, browse suggestions, approve / reject. Hard 10K SAR minimum per client to receive trades.

Demo tip: Open as Sara (not yet connected) → walk the Connect modal up to Step 3 → don't actually confirm. Then open as Saad (connected) → show the Suggestions inbox + the dashboard banner.

11 · Alpaca Model Portfolios

External model definition → link clients → per-client tweaks → sync → trade-by-trade approval. The institutional execution path.

Demo tip: The Sync Review screen is the most institutional-looking surface in the portal. Show it on a 2nd monitor if possible — the trade-by-trade approval pattern is what compliance teams care about.

12 · Performance Projections

Monte Carlo over 10k paths for any portfolio, model, or Alpaca model. Cached deterministically by scenario hash.

Demo tip: Run a 10-year horizon at 80% CI for a top client. Then change CI to 95% — fan widens visibly. Re-run with the original inputs — cache hit, instant return.

13 · Shariah Dashboard

Triage view of every non-compliant or drifting holding across the entire book.

Demo tip: Open the highest-severity alert in Saad's book. Use "Sell out" as the demo action — it's the cleanest server-action close.

14 · Zakat

Compute Zakat for any client on their portfolio + cash. Generates a per-client Hijri-dated PDF.

Demo tip: Pick a client whose Hijri year-end is within 30 days — the banner adds urgency. Generate the report, click the PDF preview.

15 · Mirath Inheritance

Compute fixed Quranic shares for any family structure. Donut visualization + per-heir table + rationale.

Demo tip: The live recalc is the magic. Increment "sons" from 2→3 mid-pitch — the donut animates and the table updates. Hits Saudi cultural relevance immediately.

16 · GOSI Gap Planning

Project a client's GOSI pension against their target retirement income; plan the bridge.

Demo tip: Pick Khalid Al-Qahtani (the retirement-planning specialist) or one of his typical client profiles. The bridge chart is the visual hook — large red gap = clear need for the advisor.

17 · Messages (WhatsApp mock)

Per-client conversation thread. Mocks the WhatsApp-Business pattern Saudi advisors actually use today.

Demo tip: Don't dwell — 30 seconds is enough. Send one Arabic message to show RTL bubbles flip correctly.

18 · Marketplace — Advisor side

Handle inbound consumer inquiries · edit the public profile · preview how the world sees you.

Demo tip: Saad has 4 seed inquiries in 4 different statuses. Open the "New" one, hit Reply with a one-line response, then jump to Profile editor and click Preview to show the consumer-facing card.

19 · Marketplace — Consumer side (public)

No auth. Anyone with a browser can discover, compare, and request a meeting with a certified advisor.

Demo tip: Open the marketplace in an incognito window during the demo (no auth) — drives home the "this is what your customers see" point. The 10 cards now show real Saudi portraits.

20 · Operational (Audit · Reporting · Billing · White-label)

Four polish surfaces that exist for institutional credibility. Less feature, more "yes it's there."

Demo tip: Spend 20 seconds on each. The White-label preview is the only one with visible interactivity — change the brand color and the mock statement re-skins live.
